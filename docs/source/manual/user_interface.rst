.. _user_interface:

User Interface
--------------

The script has a command-line user interface which allows users to customize their synthesis jobs.

A short version of command-line options can be shown by calling the help desk through

.. code-block:: yaml

  python3 scripts/run_qsyn_task.py --help 


.. option:: --help

  Show help desk to list all the options

.. option:: --list_sc_lib

  List all the available standard cell libraries in the selected PDK of task configuration file. When enabled, no task will be executed except showing a listi. Useful to perform a quick check when crafting your task configuration file

.. option:: --config <string>

  Specify the task configuration file to perform netlist synthesis jobs. See file format in `:ref:file_format_task_file` 

.. option:: --root_directory <string>

  Specify the root directory to search PDK files, netlist files etc., which are required by the task

.. option:: --custom_pdk <string>

  Specify the path to a custom PDK setting file which is not built-in. Once defined, the PDK settings in the task configuration file will be overwritten, except the corner selection.

.. option:: --report_summary <string>

  Specify the csv file where the summary of QoR will be written. The summary is extracted from the original synthesis report generated by DC runs

.. option:: --file_generation_only

  Generate input files, e.g., Tcl scripts, with which users can initiate DC runs. When enabled, skip running DC

.. option:: --parse_report_only

  Only parse the reports and generate a report summary, skip file generation and running DC

.. option:: --tasks <string>

  Specify the names of synthesis tasks to be executed. This allows users to select one or a number of tasks to be run. Use comma as a splitter, e.g., task1,task2,task3. By default, run all the listed tasks.

  .. note:: Please do not use the reserved word ``all`` as task name in your task configuration file

.. option:: --dc_rundir <string>

  Specify the name of runtime directory where synthesis runs will be executed

.. option:: -j <int> or --jobs <int>

  Specify the maximum number of jobs to be run in parallel

.. option:: --mux_modules <string>

  Specify the file name which contains a list of module names for routing multiplexers. When provided, user can access the module name in the custom SDC/Tcl file, and apply ad-hoc synthesis strategy. See details in :ref:`file_format_mux_module_file`.

.. option:: --config_mem_instances <string>

  Specify the file name which contains a list of instances names for configuration memories. When provided, user can access the module name in the custom SDC/Tcl file, and apply ad-hoc synthesis strategy. See details in :ref:`file_format_config_mem_file`.
