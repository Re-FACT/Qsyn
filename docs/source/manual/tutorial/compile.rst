How to Compile
--------------

Supported Operating Systems
~~~~~~~~~~~~~~~~~~~~~~~~~~~

DC Utility is built for Linux system only with EDA tools

- Ubuntu
- CentOS
- RedHat

It might work with earlier versions and other distributions.

Build Steps
~~~~~~~~~~~

Utility script require no build steps.

Dependencies
~~~~~~~~~~~~

Dependencies can be installed upon the use of the scripts on different systems

.. code-block::

  python3 -m pip install -r requirements.txt
