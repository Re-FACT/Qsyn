Quick Start on Synthesis Task
-----------------------------

Create a new project
~~~~~~~~~~~~~~~~~~~~

.. note:: To keep a clean project structure, we strongly recommend users to create a new directory for a new project.

A project directory in the purpose of netlist synthesis consists of the following subdirectories:

.. code-block::

  new_project
    ├── Makefile
    ├── _snps_dc_<task_name>
    ├── config
    │   └── dc_task.yaml
    ├── netlist
    │   ├── bottom_dsp_tile_icv_in_design.pt.v.gz
    │   ├── bottom_ram9k_tile_icv_in_design.pt.v.gz
    │   ├── bottom_tile_icv_in_design.pt.v.gz
    │   ├── fpga_top_icv_in_design.pt.v.gz
    │   ├── grid_dsp_tile_icv_in_design.pt.v.gz
    │   ├── grid_ram9k_tile_icv_in_design.pt.v.gz
    │   ├── left_bottom_tile_icv_in_design.pt.v.gz
    │   ├── left_tile_icv_in_design.pt.v.gz
    │   ├── left_top_tile_icv_in_design.pt.v.gz
    │   ├── right_bottom_tile_icv_in_design.pt.v.gz
    │   ├── right_tile_icv_in_design.pt.v.gz
    │   ├── tile_icv_in_design.pt.v.gz
    │   ├── top_dsp_tile_icv_in_design.pt.v.gz
    │   ├── top_ram9k_tile_icv_in_design.pt.v.gz
    │   ├── top_right_tile_icv_in_design.pt.v.gz
    │   └── top_tile_icv_in_design.pt.v.gz
    ├── sdc
    │   ├── disable_timing.sdc
    │   ├── tile_conkt_ff2fleout.tcl
    │   ├── tile_conkt_lut2fleout.tcl
    │   ├── tile_disable_routing_timing.tcl
    │   ├── tile_disable_timing.sdc
    │   ├── tile_remove_xbar_disable_timing.tcl
    │   └── tile_xbar_disable_timing.tcl
    └── spef
        ├── bottom_dsp_tile
        ├── bottom_ram9k_tile
        ├── bottom_tile
        ├── fpga_top
        ├── grid_dsp_tile
        ├── grid_ram9k_tile
        ├── left_bottom_tile
        ├── left_tile
        ├── left_top_tile
        ├── right_bottom_tile
        ├── right_tile
        ├── tile
        ├── top_dsp_tile
        ├── top_ram9k_tile
        ├── top_right_tile
        └── top_tile
  
where 

- the ``config`` directory contains the task configuration file. See details in the :ref:`file_format_task_file`
- the ``Makefile`` is the top-level makefile to run PTPX tasks. Refer to examples under ``tests/tasks``
- the ``sdc`` directory contains the SDC files which should be loaded for the current timing extraction tasks
- the ``netlist`` directory contains the HDL netlists that model the FPGA fabric
- the ``_snps_dc_<task_name>`` directory is automatically generated by DC runs, to host intermediate/temporary files. Please avoid to put important data inside.

.. note:: We strongly recommend to use zipped copy for netlist files

Once the project is initialized, fill the task configuration file accordingly.

.. note:: A shortcut to create a new project is to copy an example project, e.g., ``test/tasks/quick_test``

Run a DC task
~~~~~~~~~~~~~~~

We strongly recommend users to use Makefile when running a PTPX task, to avoid complicated setup processes.
Please refer to the ``Makefile`` examples, e.g., ``test/tasks/quick_test``.

.. literalinclude:: example_makefile

Once the setup is done, call your make target to run a DC task, for example:

.. code-block::

  make synth
